# Prometheus Kernel

The Prometheus Kernel contains the smallest reusable primitives used by Inspiration OS.

Examples of kernel-level operations include:

- evaluating reality
- comparing value
- evaluating risk
- updating state
- forming and revising beliefs
- generating basic emotional responses
- reinforcing or weakening learned scripts

Higher-level patterns belong in the [Standard Library](../library/), not in the kernel.

Inspiration OS is written in [MindScript](https://github.com/inspiration-university/mind-script).
