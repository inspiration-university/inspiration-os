# Inspiration OS Standard Library

Reusable MindScript models live here.

The library contains higher-level patterns built on top of the Prometheus Kernel.

## Categories

- `accountability/` — ownership, repair, blame, responsibility
- `attachment/` — attachment and rescuer/gateway dynamics
- `decision/` — resource-allocation and helping decisions
- `defense/` — protective psychological strategies
- `development/` — developmental learning models
- `emotion/` — higher-level emotional models
- `motivation/` — drive and persistence
- `organizations/` — group and institutional feedback loops
- `validation/` — external validation, scarcity, status, pursuit

These scripts are models, not diagnoses. Many are explicitly marked as hypotheses.
