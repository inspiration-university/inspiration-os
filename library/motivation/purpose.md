# Purpose

Purpose is an organizing direction that connects values with sustained action.

## Core Principles
- Purpose can emerge from alignment between values and behavior.
- It may evolve over time.
- Purpose does not require a grand identity or job title.

## Practices
- Rewrite a short "Why I'm Here" statement periodically.
- Audit time and commitments for alignment with stated values.
- Use long-horizon perspective to test current priorities.
